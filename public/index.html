// API Reference

Use the API directly in your own projects. All endpoints are available at https://api.lous.in — no authentication required.

POST https://api.lous.in/shorten

Creates a shortened URL. Send a JSON body with the fields below.

Request Body (JSON)
FieldTypeRequiredDescription
urlstringrequiredThe destination URL to shorten. Must be a valid HTTP/HTTPS URL.
passwordstringoptionalProtect the link with a password.
expiresAtstringoptionalExpiry date in YYYY-MM-DD format. After this date, the link returns 404.
codestringoptionalCustom short code (e.g. my-link). Must be unique — returns 409 if taken.
Request
POST https://api.lous.in/shorten
Content-Type: application/json

{
  "url": "https://example.com/some/very/long/path",
  "password": "secret123",        // optional
  "expiresAt": "2025-12-31",       // optional
  "code": "my-custom-code"        // optional
}
Response (200 OK)
{
  "code": "my-custom-code",
  "url": "https://go.lous.in/my-custom-code",
  "password": "secret123",
  "expires_at": "2025-12-31T00:00:00.000Z"
}
Error Responses
// 409 — Custom code already taken
{ "error": "Code already taken" }

// 400 — Invalid date format
{ "error": "expiresAt must be a valid date in the format YYYY-MM-DD" }

// 400 — Missing or invalid URL
{ "error": "Usage", "normal": { "url": "Link" }, /* ... */ }
GET https://api.lous.in/short/:code

Resolves a short code and redirects (302) to the destination URL. Increments the click counter and sets last_clicked_at on each visit. Returns 404 if the code doesn't exist or the link has expired.

Request
GET https://api.lous.in/short/my-custom-code
Success (302 Redirect)
HTTP/1.1 302 Found
Location: https://example.com/some/very/long/path
Errors
HTTP/1.1 404 Not Found
"Not Found"   // code doesn't exist or link has expired
JS fetch (browser / Node.js) 
// Shorten a URL
const res = await fetch('https://api.lous.in/shorten', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    url: 'https://example.com/long-url',
    code: 'my-link',        // optional
    expiresAt: '2025-12-31'  // optional
  })
});

const data = await res.json();
console.log(data.url); // https://go.lous.in/my-link
PY Python (requests) 
import requests

response = requests.post('https://api.lous.in/shorten', json={
    'url': 'https://example.com/long-url',
    'code': 'my-link',
})

data = response.json()
print(data['url'])  # https://go.lous.in/my-link
